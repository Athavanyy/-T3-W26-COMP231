# COMP231 Caalvin Assigned Tasks - Wireframe Report Design

This React/Vite package contains only the Iteration 1 tasks assigned to Caalvin Sahayathasan.

The UI is styled to match the report screenshots: a black-outlined low-fidelity screen, URL bar, left navigation, role dropdown, simple boxes, figure caption, and story notes.

## Run in VS Code

Open the folder that contains `index.html`, `package.json`, and `src`, then run:

```powershell
npm install
npm run dev
```

Open the local link Vite prints, usually:

```text
http://localhost:5173/
```

## Push to GitHub

```powershell
git status
git add .
git commit -m "Update Caalvin screens to report wireframe design"
git push origin main
```

If your branch is not `main`, use your branch name instead.
